# exercise-graph

A research-grounded corpus of individual exercises, their characteristics,
variants, and supporting evidence. Coach-assisted programming is a later workflow.
The starting corpus contains **50 draft exercise variants across 26 families**.
It includes source-linked characteristics and review notes, with Python commands
for validation, lookup, filtering, comparison, and export. No web application or
database backend has been implemented.
